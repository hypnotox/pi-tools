# Releasing

This public-source repository has no npm publication pipeline or bundled release artifact. Users install the unpinned Git repository and receive current source on a clean install or explicit package update. Git distribution keeps the installable source inspectable without adding a publication pipeline, while `AGPL-3.0-only` preserves source-availability obligations for redistribution and modification.

Keep `package.json` private. Publishing, tagging, and compatibility policy are outside the package's normal development workflow.
