Timing-extension tests live beside their implementation under `extensions/timing/`. Keep narrowly coupled tests beside a resource; place package-loading or cross-resource tests under `tests/`. Name regression tests for the behavior they protect and ensure `npm run check` runs them.
`testing/` provides the framework-neutral `pi-tools/testing` harness for shared documented Pi API and context seams. Its raw handler and direct-tool calls do not emulate Pi middleware, error conversion, or session scheduling. Keep specialized clocks, countdowns, processes, streams, and rendering fixtures in their extension domains.
