# Working with awf

awf owns this project's generated contributor workflow, documentation, and root agent guide. Edit committed `.awf/` sources and convention parts, then run `./awf render` and keep generated outputs with the source change.

This guide covers day-to-day source and render handling. [Workflow](workflow.md) owns effort lifecycle and model selection, [Debugging](debugging.md) owns recovery, and the [configuration reference](config-reference.md) owns configuration semantics.
